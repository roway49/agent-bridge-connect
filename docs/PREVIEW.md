# Feature Preview

[中文](PREVIEW_ZH.md) | English

AgentBC `1.0.2A` establishes the local task, Runner, report, resource, permission, and recovery
foundation. The following areas are planned for later releases.

## More Agents

Extend the executor and controller adapters beyond Codex, Claude Code, and
Hermes while preserving one task identity and report contract.

## Chained Dispatch

Allow a task to declare its next executor and continuation requirements so the
finishing agent can hand work to the next agent in the background without the
controller conversation waiting alongside it.

## Cross-Machine Coordination

Coordinate trusted AgentBC nodes across multiple computers while keeping task
identity, path ownership, reports, and recovery evidence explicit.

## Unified UI

Provide a visual task workspace for active, completed, failed, and recovery
queues, with report navigation and focused Runner inspection.

## More Systems And Platforms

Expand beyond the current macOS-first Alpha experience to additional desktop
operating systems, agent surfaces, and notification platforms.

This preview describes product direction, not a release-date commitment.
