# 后续功能预告

中文 | [English](PREVIEW.md)

AgentBC `1.0.1A` 已建立本地任务、Runner、报告和恢复机制。后续版本计划继续
拓展以下方向。

## 更多 Agent

在 Codex、Claude Code 和 Hermes 之外接入更多执行器与控制端，同时保持统一的
任务身份和报告契约。

## 链式派发

允许任务预先声明下一位执行者和接力要求。当前 Agent 完成后可在后台自动将工作
交给下一位 Agent，无需控制会话全程等待。

## 跨机协同

让多台受信任设备上的 AgentBC 节点协同工作，同时明确保留任务身份、路径归属、
报告和恢复证据。

## UI 界面

提供统一的可视化任务工作区，集中展示运行中、已完成、失败和待恢复任务，并支持
报告导航与 Runner 状态查看。

## 更多系统和平台

从当前 macOS 优先的 Alpha 体验扩展到更多桌面操作系统、Agent 使用界面和通知
平台。

本文仅说明产品方向，不构成具体发布日期承诺。
